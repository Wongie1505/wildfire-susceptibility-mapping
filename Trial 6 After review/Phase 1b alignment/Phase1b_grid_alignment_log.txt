PHASE 1b: GRID ALIGNMENT
========================

Status: COMPLETE for the 10 layers aligned by script. NDVI was resampled
manually before this phase (see section 10). NDMI was replaced in Phase 1c.


1. PURPOSE
----------
Phase 1 found that eight predictor rasters did not share the reference
grid (pixel size and origin) with the DEM, although all used EPSG:32736.
Phase 1b brings the predictors onto the DEM grid, so every sample point
reads the same location in every layer. The original files are not changed.


2. WHAT WAS DONE
----------------
Each raster was checked against the reference DEM grid.
- Four files already matched the grid and were copied unchanged.
- Seven files were resampled onto the DEM grid:
    categorical (LULC): nearest neighbour, so class codes are kept
    continuous:          bilinear interpolation
- Every output has a nodata value set.
- Every output was reopened and checked against the reference grid.

Folder: Phase_1b_align/
Script: phase1b_align_grids.py
Outputs: outputs/alignment_log.csv (what was done to each file)
         outputs/aligned_check.csv  (verification of each output)
Aligned rasters: data/aligned/

6. WHY IT MATTERS
-----------------
Without this step, the sample table would read each predictor from a
different location, and the model would learn from a shifted picture.
Aligning to the DEM also means every map and table in later phases uses
one grid.


7. WHAT THE DISSERTATION SHOULD NOTE
------------------------------------
- The processing grid is 30.63 m, the DEM's pixel size. Write "30.63 m",
  not "30 m". Suggested wording: "All layers were resampled to the 30.63 m
  DEM grid. Source resolutions were 500 m (MODIS NDVI and NDMI), 1 km
  (MODIS LST, resampled from a 30 m export), and 5 km (CHIRPS rainfall)."
- Rainfall is a 5 km product. It was resampled to 30 m for matching only.
  This adds no detail and must be stated as a limitation.
- Categorical LULC was resampled with nearest neighbour, so no new class
  codes were created. Bilinear interpolation was used for all other layers.
- Nodata values differ between files: DEM -32768, slope -9999, the
  distances -3.4e38 in the source (now -9999), LULC 255. State this in the
  methods, since it affects any code that reads these files.
- Nodata covers about 44 to 48 percent of each raster. This is the
  outside-boundary area. Report the study area as the cells inside the
  boundary.


8. SOURCES (confirmed by the author)
------------------------------------
- LST: MODIS MOD11A2, 1 km product, from 2000 onward. Exported from Google
  Earth Engine at 30 m. The dissertation must say MODIS MOD11A2.
- Rainfall: CHIRPS, 5 km product.
- NDVI: MODIS MOD13A3, 1 km monthly product, exported from GEE at 500 m.
  July to December median, 2002 to 2024. The time window ends at 1 January
  2025, so 2025 is excluded.
- NDMI: MODIS MOD09A1, 500 m product, July to December median, 2002 to 2024.
  Replaces the earlier Landsat-based layer (see Phase 1c).
- Landsat is not used for any predictor in the final set. The Sentinel-2
  file viphya_ndmi_s2.tif is not used anywhere in the pipeline.
