2026-11-24 | PHASE 3 RULES FIXED (before any scoring)

Decisions, recorded as agreed:
1. Headline AUC is calculated on the continuous burned_fraction (0 to 1). No threshold is applied to the headline AUC.
2. Binary label for kappa and the confusion matrix: s2_burned = burned_fraction >= 0.10. This cut-off is set for label noise, not for results. It is not chosen to improve any score.
3. Sensitivity labels, pre-declared and reported in Phase 4 whatever they show: >= 0.05 and >= 0.25.
4. Coverage rule: rows with valid_fraction < 0.5 are kept in the file but flagged usable = False, and are excluded from scoring.

Rationale for the record: the headline metric is threshold-free, so the decision about the cut-off does not affect the headline AUC. The rules were fixed before the Phase 3 build and before any Phase 4 scoring. They will not be changed after Phase 4 results are seen. Any later change must be logged as a deviation with its reason.

Scope: Sentinel-2 test years 2018 to 2024 (decision in Phase 2, option 3). 2016 and 2017 are not built.
